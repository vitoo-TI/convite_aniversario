# Convite VH 18 anos

Site estático do convite de aniversário.

## Publicar no GitHub Pages

1. Envie o arquivo `index.html` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois salve.
5. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.
